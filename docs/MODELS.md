# 公共物理模型（0.2.0 开发版）

`UUBotPhysicsModelAsset` 保存刚体、几何、惯性、关节、基础物理驱动和后端专属扩展。`FUBotPhysicsModelBuilder::Finalize` 检查数据并生成资产修订标识；运行中的模型保持不变。模型实例通过一个绑定整组注册、移除和回滚。

## 数据边界

- 模型物理数据为 SI 单位、UE 轴向。局部变换相对父刚体，根刚体相对模型坐标系。组件边界把位置转换为 UE 厘米。
- 元素 ID 是大小写敏感的字符串。`body` 与 `Body` 是不同元素；不要转成大小写不敏感的 `FName` 进行身份查找。
- 关节位置与速度布局独立：标量 1/1，球关节 4/3，自由关节 7/6。四元数为 XYZW，标量采用绝对 authored coordinate，不隐式减去原生 reference。
- 专属扩展的类型由所属后端定义，仅保存公共字段以外的语义。扩展通过 `Backend` 指明必需后端；其他后端不能悄悄忽略它。
- 原始导入文件是重新导入材料，不是运行时覆盖层。首版通过源文件修改导入物理数据，然后重新导入；已有实例必须解绑、重置后端并重新绑定新修订。

## 物理输入与状态

`FUBotPhysicsInputs` 包含执行器输入、关节广义力、世界系刚体 wrench 和运动学目标。外力以 N、力矩以 Nm 表示，在刚体原点施加。原生执行器保持各自输入维数和单位。输入是物理数据，控制策略、轨迹和失联行为由外层组件负责。

求解器拥有自己的积分状态，公共状态只是成功步进结果的只读快照。发生失败时继续提供最后有效快照；失败步不推进时间戳。连续时间后端超预算会暂停而不跳原生时间，使用显式整个后端重置后开启新时间轴。

## UE 显示与绑定

把模型资产拖入关卡，编辑器生成 `AUBotPhysicsModelActor`。它创建每个刚体的显示枢轴、几何网格和稳定 ID 映射；也可在已有 Actor 上设置 `Physics Binding.Model` 和 `Bodies[].Model Body Id`，手动绑定现有组件。

显示支持球、盒、胶囊、圆柱、椭球、平面及有显式三角形的网格。无限平面没有指定显示大小时显示为 10 m 方片，物理定义仍是无限平面。只有资源引用、尚无显示三角形的形状会报告缺少显示数据，其物理定义保留。显示组件承担查询和跨后端运动学代理，物理积分始终由后端完成。原生 visual-only 几何使用 UE `QueryOnly`，能被射线查询看到，但不产生物理接触，也不作为外部物理场景碰撞体导出。

`Physics Binding` 只控制本 Actor 的组件。无显示的其他模型刚体仍在求解器中模拟。模型实例 ID 不复用，每次重新绑定都获得新身份；旧句柄及旧回写任务不能继续使用。
